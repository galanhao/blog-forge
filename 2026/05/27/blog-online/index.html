博客上线了

2026-05-27
展开目录

新的博客终于上线了。

之前用过不少博客平台，但总觉得少了点什么。要么定制性不够，要么依赖太多。这次用自己写的 blog-forge 来构建，Markdown 写文章，推送到 GitHub，Actions 自动构建部署到 GitHub Pages，一切都干净利落。

blog-forge 的特点

  • 纯 Go 实现：一个二进制文件，没有 Node.js 依赖
  • 自定义主题规范：不绑定任何平台，可以适配任何优秀主题
  • 文章资源目录：每篇文章可以有自己的图片、视频、音频资源
  • GitHub Actions 集成：推送即部署，零运维
  • 静态优先：纯静态输出，动态能力按需叠加

接下来的计划是慢慢把之前的笔记整理出来，放到这里来。
