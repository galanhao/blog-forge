Go 项目 DDD 实践

2026-05-20
展开目录

领域驱动设计的核心思想

DDD 不是框架，不是架构，而是一种建模思维方式。

贫血模型的问题

// 贫血：数据和行为分离
type User struct {
    ID    string
    Email string
}

// 行为在外部 service 里
func ChangeEmail(u *User, newEmail string) { ... }

充血模型的改进

// 充血：数据和行为内聚
type User struct {
    id    string
    email string
}

func (u *User) ChangeEmail(newEmail string) error {
    if !isValidEmail(newEmail) {
        return ErrInvalidEmail
    }
    u.email = newEmail
    return nil
}

Go 中的聚合根

聚合根是 DDD 中最关键的概念之一。它定义了一致性边界。

总结

DDD 在 Go 中完全可以落地，关键是建模而非框架。
